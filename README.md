# Driver-Drowsiness-Detection

Computer vision and deep learning project using OpenCV and PyTorch to monitor a driver's eyes and detect fatigue in real-time.

## Technologies & Libraries Used

* **Python:** Programming language used for development.
* **OpenCV:** For real-time video capture, image processing, and Haar Cascade face and eye tracking.
* **PyTorch:** Deep learning framework used to build and evaluate the eye state classification model.
* **NumPy:** For numerical computing, array operations, and image tensor transformations.
* **Pandas:** For data handling and session logging.
* **Pygame:** For triggering audible alarm sounds during drowsiness alerts.

## Main Algorithm Used

* **Convolutional Neural Network (CNN)**
